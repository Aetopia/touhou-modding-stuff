# Touhou Modding Stuff
Collection of stuff related to Touhou Modding.

### [Touhou Community Reliant Automatic Patcher](https://github.com/thpatch/thcrap)
- Defacto tool for patching & modding Touhou games.
- Mainly used for patching in translations.
 
### [neopatch](https://github.com/astral4/neopatch)
- A patch/mod that aims to fix various issues & quirks with Touhou games. 
- "Spritual" successor to vpatch & [OpenInputLagPatch](https://github.com/khang06/OpenInputLagPatch).
- Covers the entire mainline series as well as some spinoffs.

### [thkit](https://github.com/thpatch/thtk)
- Used for unpacking Touhou games.
- Only covers the mainline games.
 
### [135tk](https://github.com/brliron/135tk)
- Used for unpacking the spinoffs made by Tasofro.
- Made for the games using the Touhou 13.5's engine.

### [th10bp](https://github.com/Aetopia/th10bp)
- My own mod that adds borderless fullscreen into Touhou 10.
  - This works akin to what you expect from any modern game.
  - Automatically preserves the game's 4:3 aspect ratio.
- If you want some development backstory, you may [view it here](https://github.com/astral4/neopatch/issues/3).
